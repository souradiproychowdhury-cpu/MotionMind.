# GestureAI

**GestureAI** is an interactive AI-powered application that combines **3D gesture control** with **AI engines for intelligent Question & Answer (Q&A)**.

## ✨ Features

* 🖐️ **3D Gesture Control** – Control the application using hand gestures.
* 🤖 **AI Q&A Engine** – Ask questions and get intelligent AI-generated answers.
* 📚 **Knowledge Integration** – Get information from knowledge sources such as Wikipedia.
* 🎯 **Interactive UI** – Simple and modern interface designed for easy interaction.
* ⚡ **Real-Time Interaction** – Perform actions using gestures without traditional controls.

## 🛠️ Technologies

* HTML, CSS & JavaScript
* 3D / Gesture Recognition
* AI / LLM APIs
* Wikipedia API
* Web-based technologies

## 🚀 Project Goal

The goal of **GestureAI** is to create a more natural way of interacting with AI by combining **gesture-based controls, 3D interaction, and intelligent Q&A** in one platform.

## 📌 Future Improvements

* Voice commands
* More advanced hand gestures
* Multiple AI models
* Offline gesture recognition
* Personalized AI assistant
